# Lesta Replays Mod

Мод для игры «Мир танков», интегрированный с сервисом [Lesta Replays](https://lesta-replays.ru/).

## Возможности

- автоматическая загрузка реплеев после боя;
- сохранение истории боёв на Lesta Replays;
- статистика игрока прямо в клиенте игры;
- просмотр результата последнего боя;
- автоматическая проверка обновлений мода.

## Установка

Скачайте:

`dist/lesta_replays_upload.zip`

Распакуйте содержимое архива в папку:

`Мир танков/mods/<версия клиента>/`

Архив уже содержит необходимые зависимости.

После установки запустите игру.

## Скачать

Актуальная версия находится в каталоге [dist](./dist).

- `lesta_replays_upload.zip` — рекомендуемый вариант установки;
- `ru.lesta-replays.upload_*.mtmod` — основной файл мода без зависимостей.
