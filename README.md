# Lesta Replays Mod

Клиентский мод для игры **«Мир танков»**, интегрированный с сервисом [Lesta Replays](https://lesta-replays.ru/).

## Возможности

- автоматическая загрузка реплеев после боя;
- сохранение истории боёв в Lesta Replays;
- статистика игрока прямо в клиенте игры;
- просмотр результата последнего боя;
- автоматическая проверка обновлений мода.

## Скачать

Готовые production-сборки публикуются в разделе **Releases**:

**[Скачать последнюю версию](https://github.com/inetsmol/lesta-replays-mod/releases/latest)**

Для обычной установки используйте архив:

`lesta_replays_upload.zip`

Он содержит основной файл мода и необходимые зависимости.

В каждом релизе также публикуется отдельный файл:

`ru.lesta-replays.upload_<build>.mtmod`

Он предназначен для случаев, когда необходимые зависимости уже установлены отдельно.

## Установка

1. Откройте [последний релиз](https://github.com/inetsmol/lesta-replays-mod/releases/latest).
2. Скачайте `lesta_replays_upload.zip`.
3. Распакуйте содержимое архива в папку:

   `Мир танков/mods/<версия клиента>/`

4. Запустите игру.
