# Lesta Replays Mod 2.6.1

Первый публичный GitHub Release мода в отдельном репозитории.

Содержит текущую production-сборку из ветки `master`: **версия 2.6.1, build 55**.

## Что вошло в текущую версию

- новое динамическое окно статистики на Gameface;
- отображение статистики игрока и показателей игровой сессии прямо в клиенте;
- компактное оформление dashboard и настройки внутри окна мода;
- автоматическая проверка и установка обновлений мода;
- проверка целостности загружаемого обновления перед установкой;
- исправленный переход со старых пакетов мода и очистка предыдущих managed-сборок;
- исправления конфликтов путей пакета и перехода с проблемной build 51.

### 2.6.1

Версия 2.6.1 является техническим обновлением относительно 2.6.0: runtime-код не менялся, версия и номер сборки были подняты для проверки механизма автоматического обновления.

## Установка

Рекомендуемый вариант — скачать `lesta_replays_upload.zip` и распаковать его содержимое в:

`Мир танков/mods/<версия клиента>/`

Архив содержит основной файл Lesta Replays Mod и необходимые зависимости.

Файл `ru.lesta-replays.upload_55.mtmod` можно использовать отдельно, если зависимости уже установлены.

Сайт проекта: https://lesta-replays.ru/
